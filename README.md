# 🎵 Music Website

A simple and elegant **music player website** that lets users listen to their favorite songs online 🎧  
Built with **HTML**, **CSS**, and **JavaScript**, it provides smooth controls and a clean design for an enjoyable experience.

## 💡 Features
- ▶️ Play / ⏸️ Pause songs  
- 🔊 Control volume (increase or decrease)  
- ⏭️ Switch between songs easily  
- 🎨 Simple and responsive design  

## 🧱 Technologies Used
- HTML5 – Structure of the website  
- CSS3 – Styling and layout  
- JavaScript – Music player functionality and buttons
